# contracts

Deployment of the shielded USDG pool on Robinhood Chain, plus Sodi's own contracts (association-set provider and session helpers).

The pool itself is [0xbow Privacy Pools](https://github.com/0xbow-io/privacy-pools-core), deployed unchanged. Sodi does not modify the audited contracts or circuits.

Tooling: [Foundry](https://book.getfoundry.sh/).
